# Questionário de Esquemas (YSQ-S3) · Essência Psi

Página única (`index.html`) do Questionário de Esquemas de Young, versão breve (YSQ-S3), aplicada pela psicóloga Eny Pimenta (CRP 07/33631).

A página não tem servidor: as respostas ficam apenas no navegador de quem responde e só saem de lá se a pessoa decidir enviar o resultado pelo WhatsApp ou salvar um PDF/arquivo no próprio aparelho. Nada é enviado ou guardado neste repositório ou no GitHub Pages.

Tradução e adaptação do YSQ-S3: J. Pinto Gouveia, D. Rijo e M. C. Salvador (2005), versão revista.
